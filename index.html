PharmaFlow Learning Lab

Điền từng field. Nhìn dữ liệu đi qua từng layer.

Bài học Lưu nháp phiếu nhập hiện toàn bộ form JSP. Bấm từng ô hoặc Field tiếp theo để xem nghiệp vụ, validate HTML vs Servlet, và sơ đồ layer. Dựa trên source Pharma_Flow.

Bắt đầu: form Nhập kho (JSP đầy đủ)

Cách học

  1. Nhìn cả form như màn hình thật (PO, header, dòng hàng, Lưu nháp)
  2. Highlight 1 field — panel phải giải thích đúng ô đó
  3. Bấm layer để xem param / code của lớp đó
  4. Lưu nháp: trace POST → validateReceipt → createDraft (kho chưa đổi)

Layer dữ liệu

  • Màn hình / JSP
  • HTTP (GET đổi PO · POST lúc lưu)
  • Servlet đọc + validateReceipt
  • DAO createDraft — chỉ khi Lưu nháp
  • Bảng GR nháp — chưa cộng tồn

Không cần Tomcat/MySQL. Số liệu [DEMO]. Đặc tả nghiệp vụ
