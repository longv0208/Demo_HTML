Khám phá cách một thao tác nhập kho đi qua HTTP Request, Servlet, DAO, Database và trở về JSP — dựa trên source code thực tế của Pharma_Flow.

Bắt đầu bài học: Lưu nháp phiếu nhập

Bạn sẽ học được gì?

  • Form JSP gửi GET/POST thế nào
  • Servlet mapping /inventory/receipts
  • doPost → handleCreate → validation
  • DAO createDraft + SQL INSERT nháp
  • Vì sao Lưu nháp không cộng tồn kho
  • Khác biệt forward và sendRedirect (PRG)

Cách dùng trong 3 bước

  1. Mở form demo — chỉnh PO / dòng hàng (dữ liệu [DEMO])
  2. Click badge vàng hoặc chọn Action bên trái
  3. Nhấn Lưu nháp / Bắt đầu mô phỏng để Trace từng bước

Không cần Tomcat hay MySQL. Mọi số liệu là [DEMO] — không ghi database thật. Đặc tả nghiệp vụ: docs/PharmaFlow_Dac_Ta_Nghiep_Vu_Nhap_Kho.md
